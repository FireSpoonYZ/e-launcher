# 对话树

视觉样式参考：`composer-tree-bottom-sheet-corrected.png`。其余旧稿已删除。树层级以用户后续确认的下述规则为准，参考稿中的层级不再作为实现依据。

- 输入框左侧独立树按钮打开底部浮层；点击遮罩、关闭按钮、返回键或向下拖动顶部手柄可关闭。
- 分叉处的不同用户输入同级显示；每个分支入口之后的内容整体再缩进一级。分支内部的连续对话保持同一深度，直到再次分叉。
- 父节点与后续节点通过连续折线连接；外侧竖线跨过整个子树连接下一个同级分支，不再以每行独立的竖线字符代替树关系。
- 任意有后代的节点可折叠整棵子树；搜索时显示匹配消息及祖先，清空搜索后恢复折叠状态。
- 点击消息只预览，当前位置仍由“当前”标记。点击底部操作才导航。
- 选择助手消息后从该节点继续；选择用户消息则回到其父节点，将原文放入输入框编辑。原后代和其他分支保留。
- 生成期间可以查看树，但不能切换历史位置。

## 存储

应用自己的 `ConversationTree` 管理历史；没有引入 coding-agent 的 SessionManager。

每条消息具有稳定 ID，树节点保存 parent ID，会话单独保存当前 leaf。旧 JSON 数组首次读取时迁移为 version 1 的对象格式，保留原文、工具调用和 incomplete 标记。已知节点按 ID 更新，新的续接追加节点，provider 的上下文裁剪不会删除树上的祖先和其他分支。流式预览、生命周期保存和最终回复共享同一消息 ID。

验证入口：`scripts/verify.ps1` 的纯 Java 树检查，以及 Android `ChatStoreChecks` 的 `-e checks store` 持久化检查。
