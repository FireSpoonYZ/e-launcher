# 实施与验证记录

实现与本地验收已完成，提交与推送在验收后执行。按用户要求，本次只做本地构建、测试和审查，不执行真机或模拟器验证。

## 设置与文件

常规入口保留通用、外观、服务商、技能、MCP、扩展、关于七类；其余 Pi 配置集中在高级配置。高级配置包含 12 个分组，提供搜索、全局／工作区范围、继承恢复，以及 Pi 0.85.1 文档中全部 65 个 settings 字段的类型和取值校验。

表单与文件编辑共用应用私有文件。JSON 在打开编辑区、手动格式化及保存时使用两空格缩进，输入过程中不重排。严格拒绝无效 JSON 和重复键，保留未知字段及原始数字写法；无效编辑不会覆盖原文件。编辑器支持草稿、导入导出、上一版和冲突提示。models.json 的完整模型、费用、兼容性和开放式覆盖结构通过完整 JSON 编辑器管理，不限定为表单列出的字段。

配置采用文件级 AtomicFile 写入。models/auth 联动修改在进程内校验原版本并回滚部分失败，不是跨文件掉电事务。凭据单独保存在私有 auth.json，OAuth 刷新和退出也走同一份存储。未修改个人全局 Pi 配置。

## Android 界面

- 通用：Agent 模式、原 Android 工具设置入口、应用权限入口，以及跟随系统／简体中文／English。
- 外观：跟随系统／浅色／深色，首页装饰圆、纯色及本地图片。图片最长边限制为 1600 像素，显示时加主题遮罩；聊天页面使用主题底色。
- 服务商：自定义服务商新增与删除、模型目录、默认模型、独立凭据编辑、OAuth 登录与退出。登录页使用系统浏览器，支持验证码、输入、选择和取消。
- 技能、扩展、MCP：原生资源诊断、启用／停用／恢复默认、包列表与管理。MCP 由扩展提供。
- 当前聊天的模型和思考强度与启动默认值分别保存。历史树入口只在聊天页顶部，并位于新建对话之前。

界面翻译只应用于明确的界面文案和内置字段标签，配置键、配置值、用户输入、模型回复和外部资源内容保留原文。主题和语言切换期间的草稿保留已通过本地回归。

## Pi 运行时

使用固定版本 0.85.1 的完整 coding-agent SDK，包含原生模型注册表、作用域设置、资源与扩展加载、工具、压缩、重试和账号接口。HTTP 初始化使用该固定版本的内部 dispatcher 入口。配置由下一次请求读取；CLI／TUI 专用设置不会改变 Android 渲染或权限。

原生会话保存实际 session header/entries，以保留压缩切点；分支恢复可补入快照后的消息。持久化绑定请求开始时的会话和节点，独立于 Activity 的 UI epoch。未完成请求或缺失已知原生上下文时拒绝静默降级成文本回放。前缀快照会占用重复空间，暂未做增量压缩。

原生包管理器的 npm／Git 来源需要运行环境具备对应命令；本地来源使用应用可访问的路径。界面会显示实际执行错误，不将保存配置或发起操作视为安装成功。

## 补齐的设计交互

- 外观：新增共享背景渲染器，首页与设置预览读取相同图片、主题及 20–100% 遮罩配置；强度纳入 `AppAppearance.revision`。拖动／键盘调节只更新预览色滤镜，不反复解码图片。可清除本机导入图并回退纯色；首页文字区另有主题色衬底，避免低强度图片影响文字对比度。原有主题／语言重建与草稿处理未改。
- 关于：通过 `PackageInfo` 显示实际 versionName 与 longVersionCode；源码及反馈固定到 FireSpoonYZ/e-launcher 与 /issues。只在用户点击后查询 GitHub `/repos/FireSpoonYZ/e-launcher/releases/latest`，分别显示读取中、HTTP／解析错误、404 无公开发布及最新发布标签／链接；不将标签差异认定为升级，不下载或安装。
- 扩展社区：Android 原生搜索框、关键词类型选择、包条目、发布者、月／周下载量、范围与配置状态、分页及安装确认。读取 npm search 的 `objects[].package`、同级 `downloads` 和 `total`；本页再次按 `pi-package` 与所选关键词过滤，分页总数为服务端搜索总数，可能有无匹配条目的页，未宣称解析包内容。
- 状态依据：实际读取固定 SDK 的 `listConfiguredPackages()` 与 `getInstalledPath()` 实现，返回 `{source, scope: user|project, filtered, installedPath?}`，installedPath 仅证明路径存在。社区默认从本机配置列出来源并明确安装未检查；用户可通过既有 `runQuery("packages")` 刷新。路径存在也明确不代表加载成功；更新／移除仍走已有包管理，安装使用校验后的固定 `npm:name@version` 并需确认。缺 npm/Git 命令等失败按既有 SDK 错误展示。未修改 `runQuery` 的归属及取消保护。
- 公共 HTTP：已有 OkHttp；连接 10 秒、读取 15 秒、整请求 20 秒，禁止重定向，响应体（包括未知长度／解压后）上限 1 MiB，查询参数编码。切页、后续请求和销毁取消旧请求并校验页面与请求编号；不执行注册表文本。所有新增界面固定文案显式 `t()`，外部包内容原样显示。
- 新增 `SettingsCatalogTest`：真实 helper 的 URL 编码、响应体上限、固定来源校验、关键词、来源边界与拦截器模拟 404/403/发布响应；不使用真实网络。`PiSettingsUiTest` 补强度 revision／边界及实际清除按钮回归。以上测试已统一执行通过。背景导入、清除及切换类型采用共享代次和提交锁，防止旧 Activity 的导入撤销新操作；社区查询、类型、页码在重建时保留，两项均有回归覆盖。
